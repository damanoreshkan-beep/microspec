# Drift

**Генеративний ембієнт-двигун — нескінченні, неповторювані, математично консонансні треки, що складаються наживо в браузері. Десять різних світів (глибокий космічний дрон, теплий плівковий луп, кришталеве скло, океанічний свел, дзен-щипок, космічний хор, тампура в чистому строї, неокласичні струнні, лоу-фай пил, лідійське мерехтіння), десять змінних звукових пакетів і три макроси. Консонанс — через прості цілочисельні співвідношення, акорди ведуться голосами задля «утримуваного дрону», а копрайм-лупи Браяна Іно роблять так, що воно ніколи не повторюється. Усе синтезовано, без файлів, офлайн.**
